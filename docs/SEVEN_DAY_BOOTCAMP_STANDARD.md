# Skillora Academy — Seven-Day Bootcamp Standard

A seven-day course teaches a **focused beginner outcome**, not mastery or guaranteed employment. The academy must publish course duration, prerequisites, learning outcomes, assessment criteria, and any instructor support before accepting payment.

## Required structure for every bootcamp

1. **Day 1 — Foundations:** short lessons, glossary, worked example, baseline quiz.
2. **Day 2 — Guided practice:** step-by-step exercise and a completed reference example.
3. **Day 3 — Independent practice:** tasks with hints, automated checks where suitable, and explanations.
4. **Day 4 — Project brief:** real-world scenario, requirements, starter resources and rubric.
5. **Day 5 — Build and test:** validation checklist, debugging guidance and accessibility/privacy reminders where relevant.
6. **Day 6 — Assessment and iteration:** knowledge check, practical rubric, feedback and revision opportunity.
7. **Day 7 — Publish and reflect:** learner submits a portfolio artifact, documents their contribution, receives a completion report and chooses next steps.

## First bootcamp portfolio outcomes

| Bootcamp | Seven-day target artifact | Assessment evidence |
|---|---|---|
| Web Development Foundations | Responsive landing page published to a learner-controlled host | Semantic HTML, responsive CSS, working navigation, accessibility checks, and a README |
| Data Analysis Foundations | Cleaned dataset plus analysis report or dashboard | Reproducible cleaning steps, correct calculations, charts with labels, and written findings |
| Digital Design Foundations | Consistent campaign set for a fictional practice brief | Design rationale, hierarchy, consistency, export quality, and rights-safe assets |
| Digital Marketing Foundations | Campaign plan, sample content, and measurement plan | Audience rationale, channel fit, content samples, KPIs, and realistic budget assumptions |
| AI Productivity for Work | Documented workflow with verification checklist | Accuracy checks, privacy-safe inputs, repeatability, source verification, and clear limits |
| Python Foundations | Tested command-line utility with README | Correctness, input validation, functions, error handling, tests, and usage instructions |

## Content quality gate

Before a course is marked publishable, require: original lesson text; worked examples; at least one meaningful exercise per learning unit; quiz explanations for every answer; a final project brief; a transparent rubric; accessibility review; technical review; and a fresh test account completing the full journey. Do not call a course job-ready solely because it has seven days of content.

## Completion and certificates

Completion must depend on the published assessment rules and backend-confirmed results. A certificate should state the course and achievement accurately. It must not imply accreditation or employment unless the academy has verifiable authorization or evidence. Reattempts and feedback should be available where practical.

## Honest catalogue rule

Do not create fake instructor profiles, employer partners, job listings, learner reviews, placement counts, or course outcomes. If a course or opportunity is not ready, label it as in development or do not publish it.
